# Security Policy

## Supported versions

Security fixes are released for the latest minor version of the module. Please upgrade to the latest release before reporting an issue.

| Version | Supported |
| ------- | --------- |
| 1.6.x   | Yes       |
| < 1.6   | No        |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests or discussions.

Report them privately through GitHub instead: open the [Security tab](https://github.com/sveawebpay/nwt-magento2-checkout/security) of this repository and click **Report a vulnerability**.

Please include:

- the module version, and the Magento and PHP versions
- a description of the issue and its impact
- steps to reproduce it, or a proof of concept
- a suggested fix, if you have one

We will acknowledge your report within 5 business days and keep you updated while we work on a fix. When a fix is released, we publish a security advisory in this repository and credit you, unless you prefer to stay anonymous.
